- autoinstall.yaml
  - Change timezone if necessary
  - Add user password hash via:     openssl passwd -6
  - Check serving machine's IP via: hostname -I
  - Initiate LAN transfer via:      python3 -m http.server <port>
      - Ensure that your firewall is not blocking <port>
  - Access from the yaml file as - http://<host-ip>:<port>/autoinstall.yaml
  - There is an installer bug where after loading the autoinstall.yaml, the wifi disconnects, so go to settings & reconnect
